# requirements/

요구사항 문서를 ISO 주차 폴더 단위로 관리한다. 진행 체크리스트는 [`tasks/`](../tasks)에 별도로 관리한다.

```
requirements/
  2026-W01/
    <요구사항 문서>.md
  2026-W02/
    ...
```

- 폴더명은 ISO 주차(`date +%G-W%V`) 기준 `YYYY-Www`.
- 그 주에 새로 들어온 요구사항을 문서 하나당 하나씩 남긴다 (기존 문서를 베이스로 변경분만 정리). 같은 주에 여러 건이 들어오면 같은 폴더 안에 파일만 늘어난다 — 하나로 합치지 않는다.
- 새 요구사항이 들어온 시점의 ISO 주차 폴더가 없으면 새로 만든다.
- 진행 체크리스트, 애드혹(문서 없는) 요청 기록은 [`tasks/README.md`](../tasks/README.md) 참고.
