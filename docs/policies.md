# 정책 (Policies)

기능별로 확정된 비즈니스 규칙을 기록한다. 정책이 언제/왜 바뀌었는지의 변경 이력은 여기 남기지 않는다 — 그 역할은 `requirements/`와 `requirements/tasks.md`가 한다. 이 문서는 항상 **현재 확정된 상태만** 반영한다.

## 인증 / 계정

- 로그인은 소셜 로그인(구글, 카카오)만 지원한다. 아이디/비밀번호 가입은 없다.
- 비로그인 사용자(게스트)도 메인 화면 열람과 로그 작성이 가능하다. 게스트 로그는 서버로 전송하지 않고 브라우저 localStorage에만 저장한다.
- 게스트 상태에서 소셜 로그인으로 전환해도, 로컬에 저장된 게스트 기록은 계정으로 이관되지 않는다.
- 회원탈퇴 시 계정과 해당 계정으로 작성된 모든 DevLog를 영구 삭제한다. 삭제된 데이터는 복구할 수 없다.

## DevLog (기록)

- 본인이 작성한 로그만 조회/수정/삭제할 수 있다. 다른 사용자의 글을 보는 소셜 피드 기능은 없다.
- `learnedNote`(배운 점)는 필수 입력, `troubleshootingNote`(버그), `tomorrowTask`(내일 할 일)는 선택 입력이다.
- 로그 작성/수정 시 기록 날짜를 선택할 수 있다. 기본값은 오늘 날짜이며, 선택 가능 범위는 오늘부터 과거 최대 1개월까지다. 미래 날짜는 선택할 수 없다.
- 검색은 `learnedNote`/`troubleshootingNote`/`tomorrowTask` 세 필드 모두를 대상으로 한다.

## 태그

- 태그는 대소문자 무관하게 동일한 태그로 취급한다(정규화 저장). 화면에 보이는 표기(`displayName`)는 최초 입력값을 유지한다.
- 로그 하나에 등록할 수 있는 태그는 최대 5개다.
- 인기 태그는 전체 사용자가 아닌 본인이 작성한 로그 기준으로 집계한다.
- 메인 화면 태그 칩은 참조(사용) 빈도가 높은 순으로 정렬하며, 최대 2줄까지만 노출하고 나머지는 숨긴다.
