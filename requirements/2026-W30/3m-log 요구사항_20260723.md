📋 [기획서] 3분 개발 로그 서비스 (3-Min DevLog)
💡 1. 서비스 한 줄 정의
개발자가 오늘 공부한 내용과 해결한 버그를 3분 만에 간편하게 기록하고, 필요할 때 검색과 태그로 다시 찾아보는 웹 서비스

🎯 2. 주요 화면 및 요구사항
화면 ① 로그인 페이지
소셜 로그인만 지원

ID/비밀번호 가입 절차 없이 구글 로그인, 카카오 로그인 버튼 두 개만 노출됩니다.

로그인에 성공하면 자동으로 메인 화면으로 이동합니다.

화면 ② 메인 화면 (로그 목록 & 검색)
상단 검색 & 태그 필터 영역

검색창: "내가 예전에 배운 내용이나 해결한 버그" 키워드를 입력하면 해당하는 기록만 찾아서 보여줍니다.

인기 태그 칩: 자주 쓰인 태그들(예: #React, #Nodejs)이 버튼 형태로 상단에 보입니다. 태그를 누르면 해당 태그가 달린 글만 필터링되어 보여야 합니다.

작성하기 버튼

클릭 시 '오늘의 로그 작성' 창(모달 또는 폼)이 나타납니다.

기록 카드 목록 (피드)

작성된 기록들이 최신순으로 카드 형태로 나열됩니다.

각 카드에는 작성 날짜, 태그들, 배운 점/버그/내일 할 일, 그리고 [수정] / [삭제] 버튼이 표시됩니다.

화면 ③ 로그 작성 / 수정 창
3가지 입력 칸 제공

💡 오늘 배운 점 (필수 입력)

🐛 해결한 버그 / 시행착오 (선택 입력)

📌 내일 할 일 (선택 입력)

태그 입력 기능

#을 붙이거나 단어를 입력하고 Enter를 누르면 태그(예: React, CORS)가 추가됩니다.

한 기록에 태그는 여러 개 붙일 수 있습니다.

⚙️ 3. 핵심 동작 규칙 (비즈니스 로직)
내 기록만 관리

내가 작성한 로그만 볼 수 있고, 수정/삭제할 수 있습니다. (남의 글을 보는 소셜 피드 기능은 지금 단계에서 제외합니다.)

태그 자동 완성 & 중복 방지

같은 태그(예: React와 react)는 대소문자 구분 없이 하나로 처리되거나 깔끔하게 묶여서 검색되면 좋겠습니다.
