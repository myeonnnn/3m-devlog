📋 [기획서] 3분 개발 로그 서비스 (3-Min DevLog) — 3차 요구사항 업데이트

이 문서는 [3m-log 요구사항_20260728.md](./3m-log%20요구사항_20260728.md)에서 정의한 요구사항 위에 추가/변경되는 요구사항을 정리한다.

## 1. 로그 작성일 선택 기능

- 로그 작성/수정 시 기록 날짜를 선택할 수 있어야 합니다.
- 기본값은 오늘 날짜입니다.
- 선택 가능 범위는 **오늘부터 과거 최대 1개월**까지이며, 미래 날짜는 선택할 수 없습니다.

## 2. 태그 개수 제한

- 로그 하나에 등록할 수 있는 태그는 **최대 5개**입니다.

## 3. 메인 화면 태그 노출 방식 변경

- 메인 화면 상단 태그 칩은 참조(사용) 빈도가 높은 순으로 정렬해 보여줍니다.
- 최대 2줄까지만 노출하고, 그 이상은 숨김 처리합니다.

## 4. 서비스명 확정

- 서비스명을 **"3m-devlog"**로 확정합니다.
- 화면 제목, 문서 등에서 "3분 개발 로그", "3-Min DevLog" 등으로 혼용되던 이름을 "3m-devlog"로 통일합니다.

## 5. 로고 제작

- 서비스 로고를 새로 제작합니다.
- 기존 다크 테마의 **터미널 GUI 컨셉**(미니멀, 모노스페이스, 시그널 컬러 포인트)에 맞춘 톤앤매너로 제작합니다.
