📋 [기획서] 3분 개발 로그 서비스 (3-Min DevLog) — 4차 요구사항 업데이트

이 문서는 [3m-log 요구사항_20260728-2.md](./3m-log%20요구사항_20260728-2.md)에서 정의한 요구사항 위에 추가/변경되는 요구사항을 정리한다.

## 1. 연속 기록 배지 (스트릭)

- 로그인한 사용자가 연속으로 기록을 남긴 날짜 수에 따라 식물이 자라는 아이콘을 보여줍니다. 숫자 대신 아이콘 단계 변화로 진행 상황을 표현합니다.
- 연속 기록 1일차부터 씨앗/새싹 단계로 시작해, 날짜 수가 늘어날수록 점점 더 크고 무성한 식물로 단계가 올라갑니다. (예: 1일차 🌱 → 며칠 후 🌿 → 더 지나면 🪴 → 오래 지속하면 🌳)
- 연속 기록 여부는 로그의 "기록 날짜" 기준으로 판단합니다. 오늘 아직 기록을 남기지 않았더라도 어제까지 연속이었다면 식물 단계는 유지됩니다.
- 연속 기록이 끊기면 다시 씨앗 단계부터 시작합니다.
- 아이콘은 메인 화면 헤더 근처에 노출합니다.
- 게스트(비로그인) 모드에는 적용하지 않습니다.

## 2. 목록 무한 스크롤

- 로그인한 사용자의 기록 목록이 많아지면, 스크롤을 내릴 때마다 다음 목록을 이어서 불러옵니다.
- 게스트(비로그인) 모드는 기존과 동일하게 전체 목록을 한 번에 보여줍니다.

## 3. 날짜 기간 필터

- 메인 화면에서 "최근 7일 / 최근 30일 / 전체" 중 하나를 선택해 해당 기간에 기록한 로그만 볼 수 있습니다.
- 기본값은 "전체"입니다.
- 기존 태그 필터, 키워드 검색과 함께 적용됩니다 (교집합).
- 로그인 모드와 게스트 모드 모두 적용됩니다.
