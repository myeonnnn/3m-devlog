📋 [기획서] 3분 개발 로그 서비스 (3-Min DevLog) — 2차 요구사항 업데이트

이 문서는 [3m-log 요구사항_20260723.md](./3m-log%20요구사항_20260723.md)에서 정의한 v1 위에 추가/변경되는 요구사항을 정리한다.

## 1. 게스트(비로그인) 이용 지원

- 로그인하지 않은 사용자도 메인 화면을 열람하고 로그를 작성할 수 있어야 합니다.
- 게스트가 작성한 로그는 서버로 전송하지 않고 브라우저 로컬 저장소(localStorage)에만 저장합니다.
- 게스트 상태에서 이후 소셜 로그인으로 정식 가입하더라도, 로컬에 저장된 게스트 기록은 계정으로 이관되지 않습니다. (기기 변경이나 브라우저 캐시 삭제 시 기록이 유실될 수 있음을 사용자에게 안내해야 합니다.)

## 2. 마이페이지 (신규 화면)

로그인한 사용자를 위한 마이페이지를 새로 추가합니다.

- 프로필 정보: 이메일, 닉네임, 로그인 방식(구글/카카오) 표시
- 내 기록 통계: 총 작성한 로그 수, 자주 쓰는 태그 등 간단한 통계
- 회원탈퇴 진입점: 마이페이지 내에 회원탈퇴로 이동하는 버튼 제공

## 3. 회원탈퇴

- 회원탈퇴 시 해당 계정과, 그 계정으로 작성된 모든 로그(DevLog)를 영구 삭제합니다.
- 삭제된 데이터는 복구할 수 없습니다.

## 4. 인기 태그 집계 기준 조정

- 메인 화면 상단의 인기 태그 칩은 "전체 사용자 기준"이 아니라 **"내가 작성한 로그 기준"**으로 집계/노출되도록 되돌립니다.
- 즉, 다른 사용자가 사용한 태그는 내 인기 태그 칩에 나타나지 않아야 합니다.

## 5. 모바일 퍼스트 디자인 개편

- 기존 다크 테마 기조는 유지하되, **미니멀함**과 **터미널 GUI 느낌의 긱(geek)한 감성**을 가미한 톤앤매너로 재정비합니다.
- 모바일 화면을 기준으로 레이아웃, 콘텐츠 간격, 터치 타겟 크기를 재정비합니다.
