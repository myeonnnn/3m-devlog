# requirements/

요구사항 문서와 진행 체크리스트를 ISO 주차 폴더 단위로 관리한다.

```
requirements/
  2026-W30/
    3m-log 요구사항_20260723.md
    tasks.md
  2026-W31/
    3m-log 요구사항_20260728.md
    3m-log 요구사항_20260728-2.md
    tasks.md
```

- 폴더명은 ISO 주차(`date +%G-W%V`) 기준 `YYYY-Www`.
- 요구사항 문서: 그 주에 새로 들어온 요구사항을 문서 하나당 하나씩 남긴다 (기존 문서를 베이스로 변경분만 정리). 같은 주에 여러 건이 들어오면 같은 폴더 안에 파일만 늘어난다 — 하나로 합치지 않는다.
- `tasks.md`: 그 주에 처리한 항목의 체크리스트. 문서화된 요구사항뿐 아니라 애드혹(문서 없는) 요청도 "요구사항 문서 없음" 섹션으로 같이 기록한다 (자세한 처리 절차는 [`CLAUDE.md`](../CLAUDE.md) 참고).
- 새 요구사항이 들어온 시점의 ISO 주차 폴더가 없으면 새로 만든다.
