## 2026-07-28-2 ([3m-log 요구사항_20260728-2.md](./3m-log%20요구사항_20260728-2.md))

### 1. 로그 작성일 선택 기능
- [x] 로그 작성/수정 시 날짜 선택 가능
- [x] 기본값은 오늘 날짜
- [x] 과거 최대 1개월까지만 선택 가능, 미래 날짜는 선택 불가 — 서버(`assertLogDateInRange`, 유닛+e2e 테스트) + 클라이언트(date input `min`/`max` + 제출 전 검증) 이중 적용. 부가로 다크 테마에서 날짜 피커 아이콘이 안 보이던 것도 `color-scheme: dark`로 같이 고침
