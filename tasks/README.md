# tasks/

요구사항 진행 체크리스트를 ISO 주차 파일 단위로 관리한다. `requirements/`와는 별도 폴더로 분리되어 있다 — 요구사항 문서(왜/무엇)와 진행 체크리스트(무엇을 끝냈는지)의 성격이 달라 섞지 않는다.

```
tasks/
  2026-W30.md
  2026-W31.md
requirements/
  2026-W30/
    3m-log 요구사항_20260723.md
  2026-W31/
    3m-log 요구사항_20260728.md
    3m-log 요구사항_20260728-2.md
```

- 파일명은 ISO 주차(`date +%G-W%V`) 기준 `YYYY-Www.md`.
- 각 파일은 그 주에 처리한 요구사항별 섹션(`## 2026-07-28 (...)`)으로 구성되며, 문서화된 요구사항은 `requirements/`의 해당 문서로 링크한다.
- `tasks/`는 `requirements/` 문서에 기반한 체크리스트만 남긴다. 문서화되지 않은 애드혹 요청(인프라/리팩터링/스타일링 등 채팅으로 바로 지시받은 변경)은 여기 기록하지 않고 커밋 메시지로 남긴다 (자세한 처리 절차는 [`CLAUDE.md`](../CLAUDE.md) 참고).
- 새 요구사항이 들어온 시점의 ISO 주차 파일이 없으면 새로 만든다.
